Networking Standards

What is IPv6?

IPv6 is the most recent version of Internet Protocol (IP). It's designed to supply IP addressing and additional security to support the predicted growth of connected devices in IoT, manufacturing, and emerging areas.

IPv6 uses a 128-bit address space, which allows for a vastly larger number of unique IP addresses compared to IPv4's 32-bit address space. Based on 128-bit addressing, IPv6 can support up to 340 undecillion addresses.

Next-Gen Routing

What is SRv6?

SRv6 (Segment Routing over IPv6) is a networking technology that extends the capabilities of IPv6 by enabling source routing and segment routing. It allows for more efficient and flexible routing of packets through a network by encoding the path that packets should take directly into the IPv6 header.

This can improve traffic engineering, reduce latency, and enhance network programmability, making it particularly useful for modern networks with complex topologies and diverse traffic patterns.
